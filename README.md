# BayesComp 2027

Official website source for BayesComp 2027, May 18–20, 2027, at Texas A&M University in College Station, Texas.

The public site is served from `index.html` through GitHub Pages. Until a custom domain is connected, it is available at <https://bayescomp2027.github.io/>.

## Updating the site

Edit or replace `index.html` on the `main` branch. GitHub Pages republishes changes automatically.

## Content status

Confirm program, registration, lodging, transportation, and deadline details with the local organizing committee before replacing any “coming soon” language.

The website includes attribution and source links for the Texas A&M campus photograph and keynote-speaker profile photographs.
